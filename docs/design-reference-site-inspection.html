Power BI page templates — "Quiet Authority"

Five page archetypes for a corporate inspection/compliance report, per your playbook. Fictional client: Meridian Facilities Group. Canvas is 1280×720 (Power BI default). Numbered dots on each page map to the notes beside it. Alternates 1b and 1c show two other treatments of the exec page.

1a Full five-page set — tinted canvas, white cards, blue data ink
Design system at a glance
Palette · same measure = same colour, everywhere
#F3F6FAPage canvas — tinted, never pure white
#FFFFFFVisual cards, 6px radius, hairline border
#24589EBrand blue = Inspections / volume (data ink)
#16324FNavy = Compliance rate lines + headings
#D9922FAmber = Targets only (dashed lines)
#C2453ARed = bad things only. Never decoration.
#3E8E5FGreen = closed / on-target, used sparingly
rampSequential blue ramp for heatmap gradient CF
Type — Segoe UI (Power BI native)
Report title 20px semibold
32 KPI number 28–32px bold
Visual title 11px caps 600
Axis / table body 10px · secondary text #5A6B7E
Signature rules
  • 24px page margins, 8px grid, consistent gutters
  • Fixed bands: title+slicers (y 8–88) → KPI band (~104px) → two content rows
  • ≤ 8 visuals per page; every visual answers one distinct question
  • Bars = ranking (always sorted) · line = trend · combo = volume vs rate · matrix+gradient = 2D pattern · table = register

Executive overview — the 10-second scan
1Title band, y 8–88. Logo + report title + subtitle with data-currency ("data to…"). Answers "is this fresh?" before anything else.
2Dropdown slicers, always top-right in the same order on every page, synced across pages. Plus a reset-filters button (bookmark).
3KPI cards ~104px: caps label · 30px number · context line (vs target, MoM Δ). Top accent bar in brand blue.
4The alarm card. Red appears on exactly one thing — the number management must act on. When they see red, it means something.
5Combo chart: volume bars (blue) + rate line (navy) on a secondary axis + amber dashed target. Three measures, three consistent colours.
6Ranking bars always sorted descending, one hue. This is the "what are we finding?" answer in one glance.
7Chase list: the actionable table. Red on the due date only — not the whole row. Column order: id → text → dims → date.

Deep-dive — the "why" page
1Heatmap = matrix + gradient CF, single sequential hue. No KPI band here — the exec page already answered "how much"; this page answers "where".
2Blank ≠ zero. Not-inspected cells stay blank (asBlank), never painted as 0% red. Dashed outline here just illustrates the gap.
3Question-level pareto — human-readable question text (displayName), never raw field names. Sorted, one hue.
4Recurrence matrix (dot size = findings) finds repeat offenders — patterns a table hides. Empty cell = clean month.
5100% stacked mix: severity trend. Red is allowed here — High severity is genuinely bad, and it's shrinking, which is the story.

Action tracker — operational page
1Lifecycle KPI band: raised → open → closed % → overdue. Green allowed on the "good" metric; red stays reserved for overdue.
2Status matrix: conditional colour only in the Overdue column, intensity by count. Neutral cells stay quiet.
3The register people work from: sorted by due date, status as quiet pills, red text only on breached dates.
4Column order: identifiers → dates/status (the actionable bits) → free text last, where truncation is survivable.
